# 我的阅读器（基础版）

一个用**原生 HTML / CSS / JavaScript** 写的单文件本地文本阅读器。
**零依赖、零构建、完全离线可用**——双击 `index.html` 就能运行。

> 课程作业，考察重点：交互设计、状态管理、本地存储。

---

## 一、运行方式

### 方式 1：本地运行（最简单，不需要任何环境）

1. 下载本仓库（`Code` → `Download ZIP`，或 `git clone`）
2. 双击 **`index.html`**，用 Chrome / Edge 打开
3. 点左上角 **「选择文件」**，选一个 **UTF-8 编码的 `.txt`** 文件
4. 正文立刻出现在工具栏下方，书架里也会多出一本书

仓库内附 `示例文本.txt`，可以直接用它测试。

> 无需安装 Node.js、无需 npm install、无需起服务器。

### 方式 2：在线演示

部署地址：https://yiyu-1024.github.io/text-reader/

## 二、功能说明

| # | 功能 | 操作方式 | 实现方式 |
|---|---|---|---|
| 1 | **打开 / 导入文本** | 点「选择文件」选 txt | `FileReader.readAsText(file, 'UTF-8')` 按 UTF-8 解码；用文件名去掉 `.txt` 作为书名；统一 `\r\n` 为 `\n` |
| 2 | **书架增删与选择** | 点书名打开，点右侧 `×` 删除 | 书全部存在 `books` 数组里，`renderShelf()` 根据数组重新生成整个列表（数据驱动视图） |
| 3 | **字号调节** | `A-` / `A+` 按钮 | 改 `readBox.style.fontSize`，用 `if` 限制在 12–40px |
| 4 | **背景色调整** | 工具栏 4 个色点 | 改 `body` 上的 CSS 变量 `--bg` / `--fg`，整套配色随之切换；当前色点加蓝圈 |
| 5 | **护眼模式** | 点「护眼模式」 | 给 `body` 加 `eye` 类，显示一层暖色滤镜 `#mask`（与背景色相互独立，可叠加） |
| 6 | **阅读进度保存** | 自动，无需操作 | 监听 `scroll` → 防抖 500ms → 计算 `scrollTop / (scrollHeight - clientHeight)` 百分比 → 写回 `books[i].progress` 并存盘 |

### 几个额外的设计

- **重开自动续读**：额外存一个 `lastId`，下次打开页面自动打开上次那本书并跳回原位置
- **空状态引导**：还没导入书时，正文区显示提示文字，避免"一片空白以为程序坏了"
- **删除前二次确认**：`confirm()` 弹窗，防止误删
- **提示栏不覆盖书名**：滚动保存时把"书名 + 字数 + 进度"拼成一句话，不会把书名顶掉

### 已知限制

| 限制 | 原因 | 进阶方向 |
|---|---|---|
| 容量约 5MB | `localStorage` 上限 | 换 IndexedDB |
| 换浏览器数据不通用 | 数据存在浏览器本地 | 后端 / 云同步 |
| 只支持 UTF-8 的 txt | 题目要求，未做编码探测 | 引入编码检测库 |
| 改字号后阅读位置会小幅偏移 | 进度锚点是"滚动像素比例"，不是段落 | 改为按段落序号锚定 |

## 三、技术栈

| 层次 | 用了什么 | 说明 |
|---|---|---|
| 结构 | **HTML5** | 左右两栏：左侧书架（240px 固定）+ 右侧阅读区 |
| 样式 | **CSS3** | Flexbox 布局、CSS 变量做主题、`transition` 做颜色过渡 |
| 逻辑 | **原生 JavaScript（ES6）** | 无框架，全部逻辑 9 个函数 |
| 读文件 | **FileReader API** | 纯前端读取本地文件，不上传服务器 |
| 存储 | **localStorage + JSON** | 书架、设置、上次阅读的书都存本地 |
| 依赖 | **无** | 不引任何框架 / 库 / CDN，离线完全可用 |

**代码规模**：单文件 443 行（CSS 约 110 行、HTML 约 40 行、JS 约 290 行）。

### 关键实现点（答辩可讲）

1. **布局**：`body { height: 100vh }` 把页面锁成一屏 → `#readBox { flex: 1 }` 让它占满剩余高度 → `overflow-y: auto` 让"只有正文自己滚动"，工具栏和书架固定不动。
2. **状态管理**：全部状态只有三个变量——`books`（书架数组）、`settings`（字号/背景/护眼）、`currentId`（当前读哪本）。**页面只是这三个变量的渲染结果**。
3. **数据流**：用户操作 → 改数组/对象 → `saveData()` 落盘 → `renderShelf()` 重画 → 界面更新。
4. **防抖**：滚动事件一秒能触发几十次，用 `clearTimeout + setTimeout(…, 500)` 保证"停手 0.5 秒才存盘"。
5. **纯文本渲染**：用 `textContent` 而不是 `innerHTML` 写正文，txt 里的任何 `<` `>` 都不会被当成标签解析。

## 四、目录结构

```
.
├── index.html        # 全部代码（结构 + 样式 + 逻辑，单文件）
├── 示例文本.txt       # 用于测试的示例 txt（UTF-8）
└── README.md         # 本文件
```

> 单文件是刻意的选择：降低运行门槛（双击即用），也便于逐段阅读代码。
